# Desired Hero Page Layout

## Key Design Elements

### Hero Section Layout
- **Full-width background image**: Modern luxury home at dusk (professionally lit)
- **Headline**: "FULL SERVICE LOW VOLTAGE CONTRACTOR" (large, bold, dark navy text)
- **Subheadline**: "Premium low voltage solutions for luxury homes and businesses in Utah."

### Top Call-to-Action Buttons
- **Residential** button (blue/highlighted)
- **Commercial** button (gray/secondary)
- **Layout**: Horizontal, organized, centered alignment
- These replace the scattered buttons currently in the site

### Feature Overlays
The hero image has interactive feature labels positioned around the house:
- Cameras
- Monitored Alarms
- Climate Control
- Lighting & Shades
- Home Theatre / Audio Visual
- Smart Lock
- Garage Door
- Custom Build Pre-Wire
- Whole-Home Network

Each label has an icon and is positioned to highlight relevant areas of the home.

### Bottom Trust Section
Dark overlay bar at bottom with three trust/benefit statements:
1. "Trusted by Homeowners & Builders - Reputation built on quality and reliability."
2. "Premium Products, Expert Installation - Top-tier brands, Flawless execution."
3. "Local Support, Long-Term Care - We're here long after the install."

### Navigation & Header
- Top navigation bar with logo (SHIELD LOW VOLTAGE)
- Menu items: Home, Services, Projects, Blog, Contact
- Blue "CALL US: (928) THE-PROS" button in top right

### Color Scheme
- Primary: Blues (CTA buttons)
- Text: Dark navy/black for strong contrast
- Accent: White text on dark backgrounds
- Professional, clean aesthetic

## Implementation Notes
- Background image should be high-quality and optimized for web
- Consider responsive design for mobile (may need to simplify feature overlays)
- Feature labels should be interactive/clickable if possible
- Maintain fast load times with lazy loading on image
